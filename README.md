# S21 Matrix+ (ver. 2.0)

Высокопроизводительная, шаблонная библиотека линейной алгебры для скалярных типов с плавающей точкой, разработанная с учетом современных стандартов C++20, принципов чистой архитектуры и численной устойчивости.

---

## 📋 Обзор

Библиотека `s21::Matrix<T>` предоставляет полный набор инструментов для работы с плотными матрицами: от базовой поэлементной арифметики до сложных операций линейной алгебры (вычисление определителя, обратной матрицы, матрицы алгебраических дополнений). 

Версия 2.0 представляет собой полный рефакторинг архитектуры: переход от зубчатых массивов (`double**`) к непрерывной модели памяти, внедрение концептов C++20 и строгих гарантий безопасности исключений.

## ✨ Ключевые особенности

### Архитектура и производительность
- **C++20 Concepts**: Строгая типизация через `std::floating_point`.
- **Непрерывная память**: Одномерный буфер (`value_type*`) с раскладкой row-major обеспечивает максимальную кэш-локальность и возможность SIMD-векторизации компилятором.
- **Явное инстанцирование**: Библиотека заранее инстанцирована для `float`, `double` и `long double`, что устраняет ODR-нарушения и ускоряет компиляцию пользовательских проектов.
- **Оптимизация алгоритмов**: 
  - Определитель: метод Гаусса с частичным выбором главного элемента ($O(N^3)$).
  - Матрица дополнений: переиспользование единого буфера минора, снижающее количество аллокаций с $O(N^2)$ до $O(1)$.
  - Умножение: оптимизированный порядок циклов (`r, k, c`) для кэш-эффективности.

### Надежность и численная устойчивость
- **RAII и Copy-and-Swap**: Строгая гарантия безопасности исключений (Strong Exception Guarantee) для всех модифицирующих операций.
- **Динамический эпсилон**: Масштабируемый порог для проверки матрицы на вырожденность, компенсирующий накопление ошибок FPU.
- **Защита от невалидных значений**: Явная обработка `NaN` и `Inf` в операторах сравнения и методе `inverse()`.
- **Защита от переполнения**: Проверка `rows * cols` на переполнение `size_type` до попытки аллокации.

## 💻 Примеры использования

### Базовая инициализация и арифметика
```cpp
#include "s21_matrix+.hpp"
#include <iostream>

int main() {
    // Инициализация через initializer_list (автовывод размерности 2x2)
    s21::Matrix<double> A{1.0, 2.0, 3.0, 4.0};
    
    // Инициализация с явной размерностью
    s21::Matrix<double> B(2, 2, {5.0, 6.0, 7.0, 8.0});
    
    // Поэлементное сложение
    s21::Matrix<double> C = A + B;
    
    // Умножение на скаляр
    C *= 2.0;
    
    std::cout << "Result matrix rows: " << C.rows() << "\n";
    return 0;
}
```

### Операции линейной алгебры
```cpp
#include "s21_matrix+.hpp"
#include <iostream>

int main() {
    s21::Matrix<double> M(3, 3, {
        1.0, 2.0, 3.0,
        0.0, 1.0, 4.0,
        5.0, 6.0, 0.0
    });

    try {
        // Вычисление определителя (O(N^3))
        double det = M.determinant();
        std::cout << "Determinant: " << det << "\n";
        
        // Обратная матрица (с проверкой на вырожденность через динамический эпсилон)
        s21::Matrix<double> Inv = M.inverse();
        
        // Проверка: M * Inv должна быть близка к единичной матрице
        s21::Matrix<double> I = M * Inv;
    } catch (const std::logic_error& e) {
        std::cerr << "Math error: " << e.what() << "\n";
    } catch (const std::invalid_argument& e) {
        std::cerr << "Invalid argument: " << e.what() << "\n";
    }
    
    return 0;
}
```

## 🔄 Миграция с версии 1.0

Версия 2.0 содержит критические изменения (Breaking Changes):
- Класс переведен в шаблонный вид `s21::Matrix<T>`.
- Пространство имен изменено на `s21`.
- Обработка ошибок переведена с кодов возврата на стандартные исключения C++ (`std::invalid_argument`, `std::logic_error` и др.).

Подробное пошаговое руководство с примерами рефакторинга кода доступно в сгенерированной Doxygen-документации на странице **@ref page_migration**.
